# LearnJSP

## Overview
LearnJSP is a personal learning repository focused on understanding and practicing **Java Server Pages (JSP)** fundamentals. This repository documents hands-on experiments, examples, and concepts learned while exploring server-side Java web development.

The goal is continuous improvement through practice, not perfection.

---

## What This Repository Contains
- JSP syntax and core concepts  
- Server-side rendering experiments  
- Practice files and learning exercises  
- Incremental commits showing learning progression  

---

## Tech Stack
- **Java**  
- **JSP (Java Server Pages)**  
- **HTML / CSS**  
- **Apache Tomcat** (or compatible servlet container)
